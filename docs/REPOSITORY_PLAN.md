# Nampinonychus Repository Plan

> **この文書の役割**：本リポジトリで**実装してよい範囲**の定義。
> **実装範囲の唯一の正**：実装してよいかの判断は本書に従う。
> [`PROJECT_ROADMAP.md`](PROJECT_ROADMAP.md) に書かれていても、
> 本書の「扱わないもの」にあるものは実装しない。
> **開発の順序と将来構想は本書に書かない**（[`DEVELOPMENT_PLAN.md`](DEVELOPMENT_PLAN.md) を参照）。

## このリポジトリの位置づけ

このリポジトリは、AIエージェントファームにおける
最初の試験エージェント「ナンピノニクス」の実装を担当する。

ナンピノニクスを実際に動かすことで、
エージェントの設計方法と `bitbank-lab-cli` の利用方法を検証する。

対象は**1個体ぶん**である。汎用化・共通化は本リポジトリの目的ではない。

## このリポジトリで扱うもの

| #   | 対象                              | 主なファイル                        |
| --- | --------------------------------- | ----------------------------------- |
| 1   | ナンピノニクスの性格設定          | `personality.md`                    |
| 2   | 売買戦略                          | `strategy.md` / `agent.yaml`        |
| 3   | リスク制約                        | `risk-policy.md` / `agent.yaml`     |
| 4   | 記憶方式                          | `memory-policy.md` / `memory/`      |
| 5   | ステータス情報                    | `status.yaml`                       |
| 6   | bitbank-lab-cli との接続          | （実装予定）                        |
| 7   | BUY・SELL・HOLD の判断処理        | （実装予定）                        |
| 8   | ペーパートレードの実行            | （実装予定）                        |
| 9   | 定期実行                          | （実装予定）                        |
| 10  | 判断ログと運用実績の保存          | （実装予定）                        |
| 11  | ナンピノニクスの HTML ステータス画面 | （実装予定）                      |

いずれも**ナンピノニクス1個体のために作る**ものである。

## このリポジトリでは扱わないもの

1. 他のAIエージェントの実装
2. 複数エージェント共通の汎用基盤
3. エージェント全体を集約する公開ダッシュボード
4. コミュニティ投稿システム
5. 3Dキャラクター生成
6. 実資金による取引

また、`bitbank-lab-cli` 本体の実装も扱わない。
本リポジトリは CLI を**利用する側**であり、CLI への改善は
上流リポジトリへの Issue・Pull Request として提案する。

## 範囲の判断に迷ったとき

「扱うもの」にも「扱わないもの」にも当てはまらない依頼は、
勝手に判断せず、次の手順で確認する。

1. ナンピノニクス1個体を動かすために必要か
2. 他のエージェントにも使える汎用機能になっていないか
3. **1 が「はい」かつ 2 が「いいえ」のときだけ扱う。** それ以外は指示を仰ぐ。

判断がつかない場合は実装せず、範囲の確認を求める。

## 前提と制約

本リポジトリの実装は、以下を常に満たす。詳細は [`../CLAUDE.md`](../CLAUDE.md) を参照。

- 実資金による取引を行わない（ペーパートレードのみ）
- 数値パラメータの正は `agent.yaml`
- `personality.md` と `risk-policy.md` が矛盾する場合は `risk-policy.md` が勝つ
- 判断できないときは HOLD
