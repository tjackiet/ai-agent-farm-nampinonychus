# AI Agent Farm Project Roadmap

> **この文書の役割**：AIエージェントファーム**企画全体**の地図。
> **対象範囲**：複数リポジトリ・複数エージェントにまたがる企画全体。
> **作業指示ではない**：本リポジトリで実装してよい範囲は
> [`REPOSITORY_PLAN.md`](REPOSITORY_PLAN.md) にのみ定義される。
> **本書の項目を、本リポジトリの作業対象と解釈しないこと。**

AIエージェントファームは、個性を持つ投資AIエージェントを育成し、
ペーパートレードによるフォワード運用を観察するプロジェクトである。

## 本リポジトリの位置づけ

```
AIエージェントファーム（企画全体）        ← 本書が説明する範囲
├── 共通基盤・ダッシュボード（別リポジトリ）
├── bitbank-lab-cli（外部リポジトリ／利用するだけ）
├── bitbank-lab-mcp（外部リポジトリ／本リポジトリでは利用しない）
└── エージェント個体のリポジトリ群
    ├── ai-agent-farm-nampinonychus      ← 本リポジトリ
    └── （今後増える他のエージェント）
```

本リポジトリ（`ai-agent-farm-nampinonychus`）が担当するのは、
**エージェント個体「ナンピノニクス」1体ぶんだけ**である。

企画側の共通基盤・ダッシュボード・CLI 本体は、いずれも本リポジトリの外にある。

## エージェントが利用するツール

bitbank には、性格の異なる2つの姉妹プロジェクトがある。

| ツール                                                          | 提供するもの                                     | 本リポジトリでの扱い     |
| --------------------------------------------------------------- | ------------------------------------------------ | ------------------------ |
| [`bitbank-lab-cli`](https://github.com/bitbankinc/bitbank-lab-cli) | 生データを取得し、判断は LLM 側で行う。ペーパートレードを含む | **エージェントが利用する** |
| [`bitbank-lab-mcp`](https://github.com/bitbankinc/bitbank-lab-mcp) | 計算済みのテクニカル分析結果を LLM に渡す        | **利用しない**           |

ナンピノニクスは、アンカー（直近2時間の高値）も階段の指値価格も自分で計算し、
ペーパートレードで発注する。**生データと発注手段の両方が必要なため、CLI を使う。**

`bitbank-lab-mcp` は別リポジトリで開発されており、本企画とは独立している。
本リポジトリの実装対象でも、利用対象でもない。

## プロジェクトの構成

企画として達成したいことの一覧。**どこで実装されるか**を併記する。

| #   | 項目                                             | 実装する場所                                             |
| --- | ------------------------------------------------ | -------------------------------------------------------- |
| 1   | AIエージェントを構築する                         | 各エージェントのリポジトリ（本リポジトリを含む）         |
| 2   | bitbank-lab-cli と接続する                       | 各エージェントのリポジトリ（本リポジトリを含む）         |
| 3   | ペーパートレードでフォワード運用する             | 各エージェントのリポジトリ（本リポジトリを含む）         |
| 4   | 判断と運用実績を保存する                         | 各エージェントのリポジトリ（本リポジトリを含む）         |
| 5   | エージェントの性格とステータスを可視化する       | 各エージェントのリポジトリ（本リポジトリは自分のぶんのみ） |
| 6   | 成績に応じてキャラクターのエモートを変化させる   | 各エージェントのリポジトリ（本リポジトリは自分のぶんのみ） |
| 7   | 複数のエージェントを比較できるダッシュボードを作る | 企画側の別リポジトリ（**本リポジトリの範囲外**）         |
| 8   | 参加者がエージェントを作成・共有できる仕組みを整える | 企画側の別リポジトリ（**本リポジトリの範囲外**）      |
| 9   | 利用過程で発見した改善を bitbank-lab-cli と MCP に還元する | `bitbank-lab-cli` / `bitbank-lab-mcp` 側。本リポジトリからは Issue・Pull Request で提案するのみ |

> 項目 9 の「MCP」は `bitbank-lab-mcp` を指す。CLI・MCP のいずれも
> 本リポジトリの外で開発されており、**本リポジトリからは Issue・Pull Request で
> 改善を提案するだけ**である。エージェントに組み込むのは CLI 側のみ。

## 主な開発領域

| 開発領域         | 内容                                       | 本リポジトリの関与                     |
| ---------------- | ------------------------------------------ | -------------------------------------- |
| エージェント     | 性格、戦略、リスク、記憶、判断処理         | ナンピノニクス個体ぶんを実装する       |
| CLI              | 市場データ取得、ペーパートレード、複数口座対応 | **利用するのみ。CLI 自体は実装しない** |
| 運用基盤         | 定期実行、ログ、実績保存                   | ナンピノニクス個体ぶんを実装する       |
| 可視化           | ステータス画面、キャラクター、エモート     | ナンピノニクスのステータス画面のみ     |
| ダッシュボード   | 成績、判断履歴、稼働状態                   | **関与しない**                         |
| コミュニティ     | テンプレート、共有、Issue、Pull Request     | **関与しない**                         |

## 企画全体の前提

参加するすべてのエージェントが共通して守る前提。

- 実資金による取引は行わない。ペーパートレードのみを対象とする。
- 市場データ取得と発注は `bitbank-lab-cli` を経由する。
- 判断の根拠と結果を、あとから人間が追える形で残す。
- 本企画の成果物は投資助言ではなく、利益を保証しない。
